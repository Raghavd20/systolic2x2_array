# 2x2 Systolic Array – Verilog

This project implements a 2×2 systolic array for matrix multiplication in Verilog.

## Features
- Processing Element (MAC with internal accumulation)
- Correct systolic dataflow
- Cycle-skewed input scheduling
- Verified using testbench

## Folder Structure
rtl/  → RTL modules  
tb/   → Testbench  
sim/  → Simulation outputs  

## Result
Matrix multiplication output:
19 22
43 50
